## Usage Rules

- **Never name students.** All elementary classroom quotes → "a student" or "students."
- **Always contextualize.** Introduce each quote with its session context (e.g., "During a grade 4 Minecraft coding challenge...").
- **The seminar quotes** are in the voice of the instructor/facilitator — attribute as "the course instructor" or "the seminar facilitator."
- **Timestamps** from the seminar transcript are approximate (marked with `~`); the `.md` grade-4 transcripts have cleaner section headers.
