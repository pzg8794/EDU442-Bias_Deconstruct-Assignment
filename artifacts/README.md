# Artifacts (Evidence + Identity Context)

This folder organizes the *evidence sets* and *identity/journal artifacts* referenced in the paper `main.tex`.

## What these artifacts are
- **Evidence Sets (E1–E4)** are time-stamped, verbatim observation records (classroom talk, mentor feedback conversation, and a course seminar discussion).
- Each evidence set has a matching `E#_*.md` summary with:
  - source file path
  - anonymization notes
  - key excerpts (with line references)
  - what claims the excerpts support
  - where the evidence is used in the paper

- **Journal Artifacts (J1–J3)** are author identity/positionality artifacts (journal writing + a course roundtable excerpt) used to make the paper’s purpose and tone auditable.

## How the paper cites them
- The paper references these materials as **Evidence Set E1, E2, E3, E4** (or simply **E1–E4** after first definition).
- The paper references identity materials as **Journal Artifact J1, J2, J3** (or **J1–J3**).
- These artifacts are **not** included in the References list because they are unpublished observation records and/or private journal writing.

## Privacy / ethics
These records contain sensitive classroom and practicum information.
- Student names are anonymized in the paper and in the excerpts below (e.g., `[Student M]`).
- Only excerpts necessary to support the paper’s claims are reproduced.

Journal artifacts are also personal writing; they are included for traceability, not for public circulation.
